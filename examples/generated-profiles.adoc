= Sample Generated Profiles

This is documentation-only sample output. The real generated profiles depend on the active host session, especially `XDG_RUNTIME_DIR`, `WAYLAND_DISPLAY`, `DISPLAY`, PipeWire, and Pulse socket paths.

The generated profiles are what the launch command uses:

----
$ incus launch images:archlinux/cloud osu --profile default --profile gui --profile osu
----
